YN 3D — موقع معرض معماري وجولات افتراضية 360°
================================================

هذه نسخة تأسيسية أولى لموقع مستقل بتصميم داكن وفخم وهوية مؤقتة YN 3D.
تعتمد الجولة الافتراضية على مكتبة Marzipano مفتوحة المصدر.

محتويات الموقع
--------------
index.html       الصفحة الرئيسية ومعرض المشاريع
 tour.html       عارض الصور البانورامية 360°
css/             ملفات التصميم
js/              وظائف الموقع و مشغل الجولة
assets/          مكان الصور والبانوراما

تجربة الصور البانورامية محلياً
-----------------------------
1) افتح الموقع عبر خادم محلي (لا تفتح tour.html بالنقر المزدوج).
2) إذا كان Python مثبتاً على Windows:
   - افتح مجلد الموقع.
   - اكتب cmd في شريط عنوان File Explorer واضغط Enter.
   - نفّذ: py -m http.server 8000
   - افتح: http://localhost:8000
3) افتح Virtual Tour ثم اختر صورة أو عدة صور بانورامية من D5 Render.
4) يجب أن تكون الصور بصيغة equirectangular بنسبة 2:1 (مثلاً 6000×3000).
5) الصور المختارة في صفحة التجربة تبقى محلية داخل المتصفح ولا تُرفع إلى الإنترنت.

إضافة مشروع منشور بشكل دائم
--------------------------
هذه النسخة التأسيسية تعرض صفحة الجولة مع أداة معاينة محلية. عند تجهيز مشروع حقيقي:
- ضع صور المشروع العادية داخل assets/images/.
- ضع صور البانوراما أو ملفات الجولة المصدرة من Marzipano داخل مجلد المشروع.
- أنشئ صفحة مستقلة للمشروع أو عدّل روابط البطاقات في index.html.
- لا ترفع صور بانورامية ضخمة مباشرة إلى Cloudflare Pages إذا تجاوز الملف الواحد 25 MiB؛ استخدم ضغطاً مناسباً أو تخزيناً للملفات الكبيرة مثل Cloudflare R2.

مهم حول Hotspots
----------------
المعاينة الحالية تربط المشاهد المتتالية بنقطة انتقال تجريبية. مكان نقطة الانتقال افتراضي في منتصف مجال الرؤية؛ في النسخة النهائية يجب ضبط مواضع الأسهم حسب اتجاه الأبواب والممرات في كل صورة.

تخصيص الهوية
------------
- الاسم الظاهر حالياً: YN 3D / YASSINE NASSIR.
- الشعار الحالي كتابة مؤقتة وليس ملف شعار نهائي.
- عدّل بيانات التواصل في index.html قبل النشر (hello@example.com مجرد عنوان تجريبي).
- صور Unsplash في الصفحة الرئيسية صور تجريبية يجب استبدالها برندراتك الخاصة.

النشر المجاني
-------------
يمكن نشر ملفات الموقع الثابتة على Cloudflare Pages. أنشئ مشروع Pages وارفع مجلد الموقع بعد تجهيز صورك وبيانات المشاريع. راجع حدود الملفات وحجم الملف الحالي في وثائق Cloudflare قبل نشر جولات عالية الدقة.
